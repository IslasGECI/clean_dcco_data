## Description

R package for cleaning and processing Double-crested Cormorant (*Nannopterum auritum*) nesting count data from islands in the Gulf of California and Pacific coast.
It computes maximum active nests per season and island, concatenates historical and recent count datasets, filters islands by region, and generates figure metadata for population trend analysis.
